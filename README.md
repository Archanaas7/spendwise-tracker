SpendWise 💰

A simple and responsive personal expense tracker built to help users manage their income, expenses and monthly budgets.

📌 Features

- Add income and expenses
- Custom expense categories
- Edit transactions
- Delete transactions
- Search transactions
- Filter income and expenses
- Monthly budget tracking
- Budget progress indicator
- Automatic balance calculation
- Dark mode
- Data persistence using browser localStorage
- Responsive design for desktop and mobile

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- GitHub Pages

📱 Responsive Design

SpendWise is designed to work across desktop and mobile screen sizes.

🎯 Project Goal

The goal of SpendWise is to create a simple personal finance interface that allows users to record and understand their everyday spending.

🔮 Future Improvements

- User authentication
- Cloud database
- Multiple currency support
- Expense analytics
- Monthly and yearly charts
- Recurring transactions
- Export transactions
- Firebase integration
